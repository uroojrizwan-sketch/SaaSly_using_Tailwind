## 📌 About The Project

**SaaSly** is a modern SaaS website landing page designed to showcase a web design service with a clean, dark-themed interface.

The page includes a navigation bar, hero section, core features, pricing plans, contact form, and footer.

I developed this project using HTML5 and Tailwind CSS to practice utility-first styling, responsive layouts, and building structured landing pages.

## ✨ Features

- 🧭 **Navigation Bar:** Includes links to Features, Pricing, and Contact sections.
- 🚀 **Hero Section:** Promotional heading, description, call-to-action button, and development-themed image.
- ⚡ **Core Features:** Highlights fast performance, responsive design, and easy customization.
- 💳 **Pricing Plans:** Three pricing options: Basic, Pro, and Enterprise.
- 📩 **Contact Form UI:** Includes first name, last name, email, message, and terms checkbox fields.
- 🦶 **Footer Section:** Includes website branding, navigation links, and social icons.
- 📱 **Responsive Layout:** Uses Tailwind responsive utility classes for different screen sizes.
- 🌙 **Dark Theme:** Uses a dark background with blue accent colors.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/uroojrizwan-sketch/SaaSly-Using-HTML.git
```

### 2. Open the Project Folder

```bash
cd SaaSly-Using-HTML
```

### 3. Open the HTML File

Open `final-Saas.html` in your browser.

**Important:** The HTML file references `./src/output.css`. Make sure the generated Tailwind CSS file is available at that path; otherwise, the page's Tailwind styling will not load correctly.
